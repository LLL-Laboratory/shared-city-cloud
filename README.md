# LLL Laboratory Shared City Cloud

**Status:** PUBLIC READ-ONLY PROTOTYPE / FOR REVIEW

This repository contains the bounded static preview of LLL Laboratory's Shared
City Cloud. Its primary surface is an original 3D research-atlas world with a
same-data non-3D Navigator.

Live preview:
[https://lll-laboratory.github.io/shared-city-cloud/](https://lll-laboratory.github.io/shared-city-cloud/)

## Research state

- `SLC-0001` remains `DRAFT / FOR TEAM REVIEW`.
- Its shared-memory effect remains `NONE`.
- Food, Money, and Sand remain equal, separate, and individually
  `UNKNOWN / NOT ESTIMABLE`.
- `CLM-01 ACCEPT` and `CLM-02 HOLD` are claim-level decisions only. Neither
  approves the full record.
- Selecting `SLC-0001` reveals nine traceable source-register nodes with their
  evidence label, claim scope, and source limitation. A source node is not a
  source image or new evidence.
- **Open Questions** keeps existing `HOLD`, `UNKNOWN / NOT ESTIMABLE`, and
  proposed evidence requests together without rendering them as outcomes.
- **Conflict View** compares the official rain/lagoon explanation, unresolved
  drainage pathway, BRT mobility factor, and intervention-versus-recession
  pathway. Every causal pathway remains `HOLD` or
  `UNKNOWN / NOT ESTIMABLE`.
- Spatial position, motion, routes, City Pulse, and Path Replay are interface
  demonstrations, not analytics or empirical conclusions.
- Spatial proximity is navigation, never evidence.

## Public boundary

This repository contains only the validated static preview, its byte manifest,
and minimal public documentation. The underlying research authorities, local
record system, handovers, rejected prototypes, credentials, and private
workspace are intentionally not published.

The preview is read-only. It has no identity system, database, external AI,
MCP/API, analytics, automatic chat capture, external data collection, or
hosted research storage.

## Navigation

- Drag to orbit and scroll to approach or move away.
- Select an object to open its focused reading layer.
- Use **Whole world** to return.
- Use **Navigator** for the same information without 3D navigation.
- Keyboard shortcuts: `E` Evidence Constellation, `Q` Open Questions, `C`
  Conflict View, `T` timeline, `H` guided handover, `N` Navigator, and
  `Escape` to close the active layer.

Deployment details and verification boundaries are recorded in
[`DEPLOYMENT.md`](./DEPLOYMENT.md).
